# Contest Bot

A Discord bot built with `discord.js`, `dotenv`, and `node-cron`.

## Setup and Run Instructions

1. Make sure you have installed all dependencies:
   ```bash
   npm install
   ```

2. Make sure your `.env` file is properly configured with your bot token and any other required variables.

3. Run the bot using Node.js:
   ```bash
   node index.js
   ```
